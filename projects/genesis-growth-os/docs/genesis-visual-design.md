# Genesis 整体视觉统一

## 设计依据

参考本项目原有 Daily Quest 的火焰、铁砧、冷却场景和中性角色形象，采用保留品牌的视觉改造。使用 taste skill 的审查、层级、对比度、布局和减少动画规则；产品现有 Express、原生 HTML/CSS/JavaScript 和离线字体继续复用。

原页面采用暗色底、暖金强调、系统中文字体及 Outfit。主要问题是辅助字号过小、重复的面板嵌套、使命卡片过高，以及档案和设置之间的操作样式不一致。导航、路由、字段顺序和现有内容保持一致。

视觉参数：布局变化 4 / 动效强度 4 / 信息密度 6。动效服务于悬停、状态确认和锻造场景，不新增持续装饰动画。

## 各页面

- 首页：角色为中心，钢灰面板统一主线、近期成长、能力积累和行动维度。数字、正文、来源使用不同层级，空状态保留。
- 我的角色：保留中性角色画布、真实资料和编辑入口，统一形象底座及文字层级。
- 每日使命：创建输入、真实进度和原锻造场景构成工作台；下方为按时间排列的紧凑使命行，开始、完成、撤销和管理菜单沿用已有逻辑。
- 成长资产库：项目、复盘、资产和来源证据采用一致面板及操作样式；保留查看、编辑和关联项目。
- 设置：角色字段和连接来源延用相同材质，表单与弹窗共享可辨识的焦点及按钮样式。

## 边界

颜色和间距由 `public/css/11-genesis-workshop.css` 统一，复用原有尺度。炉火和主要操作使用暖金，正文使用暖灰，按钮采用深色文字提高对比度。

角色卡的暖金光晕扩展到全站：背景与导航提供微弱环境光，主面板与资产卡使用底部径向光和边缘晕光，按钮与进度条有更明确的亮度。光感由静态 CSS 渐变及阴影实现，无覆盖交互的图层、无持续闪烁、无新增脚本。卡片中央维持深色，保持正文和表单的阅读对比度。

本次不改数据库结构、奖励机制、保存接口或认证。页面加载、刷新、切换只读取成长数据。原 Forge 和 Genesis 的业务测试必须继续通过。

移动端使用单列布局，使命时间进入卡片，表单单列显示。所有主动操作的点击区域至少 44px。系统开启减少动画后关闭过渡、悬停位移和动画；画布继续沿用既有静态降级与任务按钮。

发布时更新 HTML 资源版本与服务工作线程缓存，并运行语法、完整回归及云端静态资源构建。构建不会部署。
