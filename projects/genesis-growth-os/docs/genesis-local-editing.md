# Genesis 本地界面与成长档案编辑

本轮完成用户标注的八处调整，延续原有 Express、原生前端与 UI 组件。仅启用本地测试预览，不进行云端部署，不增加数据库表，不调用 LLM API。

## 使命体验

- 快捷输入旁只保留一个「创建使命」按钮。
- 每日使命按计划时间排列，没有时间的排在最后；不再提供拖动或手动顺序入口。原排序 API 保留用于兼容，不由新页面调用。
- 进度区域复用原火炉、铁砧、冷却和完成架的画布。点击使命加热，再敲击铁砧，或使用卡片上的开始、完成、撤销按钮。
- 画布接入现有行动保存接口，不调用 Game、奖励检查或经验计算。服务器确认前不显示完成架，失败回到待开始的画布位置；重复点击互斥。
- 加热与敲击只是反馈交互，不证明现实行动已发生。完成状态仍是用户自我报告，不自动生成复盘、资产或能力证据。
- 暂停、未来和软删除使命移入折叠管理区，保留恢复能力；已有历史任务不自动迁移。
- 画布仅在使命页启动，离开或后台隐藏时停止。减少动态效果模式使用静态展示及下方卡片按钮。

## 本地人工编辑

设置 `GENESIS_ENABLE_LOCAL_EDITING=1` 显式开启；默认关闭。Cloudflare Worker 未增加编辑接口，云端页面不会显示这些编辑入口。

- 项目：名称、描述、状态、领域、手动进度、下一步。
- 成长记录：标题、正文、项目关联和实际完成、问题、方案、知识、经验、下一步。没有把计划自动算作完成。
- 资产：独立卡片，可查看完整内容并编辑标题、类型、正文、标签和项目关联。
- 角色：昵称、当前阶段、成长路线；设置和角色卡共用编辑弹窗。没有预填未经确认的角色设定。
- 原始来源、证据、Git 引用不可在普通表单中修改。来源及修改前内容保存在本地私有审计记录，每条保留最近 40 次修改；手动修改标为用户自述。
- 请求使用既有登录会话、跨站拦截、字段/长度/关联验证、更新时间版本与幂等请求键。失败保留输入，不自动重试。
- Agent 后续保存已人工编辑的项目时，返回已保存的人工版本与 `manual_preserved: true`，不会覆盖它；仍可添加新的成长记录和资产。

## 无损项目合并

本地预览中的三个 Genesis 项目按用户要求归为一个可见项目。保留最晚 Codex 同步项目作为主条目，保留另外两条原始项目数据和 `source_ref`。关联复盘、资产及使命指向主项目；旧 ID 可继续读取主项目。

合并关系使用现有 `settings` 的 `genesis_project_aliases` 保存，原始条目及修改前内容使用 `genesis_manual_edit_history` 保存。没有新增迁移，没有物理删除。页面和 Agent 查询按主项目统计，不再把别名当成三个项目；证据引用和下一步合并去重，进度保留主项目值，没有将不同历史进度相加或推断完成程度。

## 数据安全与验证

操作前创建完整 SQLite 备份，保存在工作区之外的私有本地验收目录。自动化测试使用临时数据库，浏览器验收使用当前预览库的隔离副本；测试角色和测试内容没有复制到用户预览库。

已验证：

- 全套 27 个测试脚本及语法检查、静态构建。
- 真实 Express/SQLite 的编辑、版本冲突、重复请求、字段校验、认证、跨站保护、私有来源与证据保留、合并、原条目保留。
- 新接口 100 次读取不写入任何表或新增表。
- 浏览器中的角色、项目、成长记录和资产编辑保存，刷新读取。
- 画布真实点击加热与敲击后，通过现有行动接口完成测试使命。
- 100 次真实页面刷新前后，14 张表的内容与结构完全一致。
- 停止隔离服务后保存：明确提示网络不可用、未确认保存，输入保留，数据库不变；恢复服务后不自动重试。
- 390 像素窄屏的编辑弹窗没有横向溢出。此项为浏览器尺寸验证，不是手机真机验收。

完整 SQLite 备份包含编辑审计及合并关系。旧 JSON 备份协议不保证包含所有 Genesis 表，仍建议使用完整数据库备份。没有执行远程 D1 操作或生产部署。
