# 首次设置自己的登录密码

独立测试 Worker 开启 `GENESIS_ENABLE_OWNER_SETUP=1` 后，第一次使用由本人设置登录密码。Genesis 为单用户私有仓库，不向任意访客开放抢先注册。部署只增加空的认证表，不替用户选择密码。

## 用户流程

1. 管理者在本机受保护环境生成有效期最长24小时的专属初始化链接。
2. 本人打开链接，填写两次新密码（12–256字符，建议使用独特长口令）。
3. 服务端首次保存成功后自动登录；之后电脑、手机使用同一新密码。
4. 初始化接口关闭；再次访问设置页进入登录页。其他访客及过期链接不能设置或覆盖密码。

证明放在URL fragment中，页面立即移除，只保留在本页内存；通过请求头提交，不进入查询字符串、Referer、浏览器本地存储或应用日志。若关闭页面或刷新导致证明丢失，在初始化完成前可重新打开原专属链接。不要把该链接作为公共安装链接转发。

## 实现与安全边界

- 增量迁移 `0008_genesis_owner_auth.sql` 创建单行 `genesis_owner_auth`，不修改任何项目、使命、技能或个人档案。仅在主动设置成功时插入；`INSERT OR IGNORE`保证并发认领只有一人成功。
- 只保存32字节随机盐、PBKDF2-SHA256派生值、参数、会话代次和创建时间。没有明文密码。
- 原 `GENESIS_VIEW_PASSWORD` Secret 保留，作为独立于D1的HMAC pepper和初始化证明／会话签名根密钥。新密码设置后原Secret值不再可以登录。不能随意删除或替换此Secret，否则派生值验证和会话将失效。
- Worker WebCrypto使用100000次迭代，与当前运行时上限兼容；Secret pepper增加仅D1泄露时的保护。不能将此参数包装为符合OWASP的600000次PBKDF2基线；需要生产发布时单独评估KDF和平台成本。
- 初始化后的会话使用新代次签名，旧会话失效。仍为8小时、Secure／HttpOnly／SameSite=Strict；Agent Token和接口不改变。
- 初始化严格检查同源、有效签名及有效期、弱密码、长度与并发；登录和设置使用已有Cloudflare限流。服务器不打印请求正文、密码、盐／哈希或证明。
- Agent不能初始化密码；没有公开密码重置接口。遗忘密码须管理者进行经过授权的恢复，不因访问页面自动清空认证表。
- 本地Express继续沿用原有首次设置和SQLite存储，不启用此D1方案。

## 测试

真实本地D1/workerd验证：并发认领唯一、非法／过期证明拒绝、跨站拒绝、长度和弱密码拒绝、没有明文、旧密码和旧会话失效、新密码登录、重复初始化关闭、Agent读取不变、项目数据不变。前端验证专属证明移除、未授权及离线禁提交、确认后主动保存、本地页面兼容。

远程验收不替本人设置真实密码，只检查空认证表、合法／非法初始化状态、中文设置页面、Agent和原业务记录。真实新密码由本人输入，因此最终设置和首次新密码登录由本人完成。
